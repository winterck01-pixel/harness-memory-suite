# 媒体工坊与 MCP 扩展

这组可选插件包括图片工坊、镜头工坊、图片/视频任务引擎、媒体预览、共享任务状态以及手机图标中的 MCP 服务管理。可灵和 WorkRally 各自使用独立模型目录、账号配置、命名空间和任务查询协议。

## 安装

在仓库根目录使用 Node.js 22.19+ 或 24，安装依赖并构建；镜头导入、媒体探测和导出还需要 ffmpeg、ffprobe 在 PATH 中。

```sh
npm ci
npm run prepare:host
npm run build
```

插件配置仍由部署者合并进现有 Harness profile，配置生成器不会自动启动服务。不要重复加载已有插件。文件管理器继续使用本仓库 `file-manager`，它提供媒体废纸篓的共享操作。

```sh
node scripts/write-media-host-config.mjs \
  --plugins-root "$PWD/packages" \
  --out "$HOME/.dsh/media-plugins.local.json"
```

配置生成器仅写部署者本地文件，输出权限为 0600，不覆盖已有输出或不同内容的桥接程序。使用与 Harness 相同的 HOME。需要自定义连接清单位置时，在配置生成器和 Harness 服务中设置相同的 `DSH_REMOTE_CONNECTIONS_PATH`。清单、令牌、授权缓存、任务和用户素材均不得提交 Git。

百度网盘是可选连接。使用独立 Python 环境安装 `mcp-proxy==0.13.0`，将官方完整 SSE 授权链接放入 `BAIDU_MCP_URL` 环境变量，再运行生成器；通过 `--python` 指定该环境的 Python 绝对路径。需要本地上传时，通过 `--upload-program` 指定已经安装的官方上传程序。仓库只提供受控启动包装，不复制第三方上传程序，也没有迁移旧连接文件的后备路径。

WorkRally 也是可选连接。初次配置可通过 `WORKRALLY_MCP_TOKEN` 环境变量提供自己的认证值。未提供认证的连接保持禁用；已有配置由部署者审查后合并，后续修改在手机图标的服务卡片完成。不要将令牌放入命令行参数、截图或提交中。

可灵使用固定版本 `mcp-remote@0.2.0`。生成器为本机安装计算 SDK 文件校验值，并配置授权适配器；从可灵卡片点击授权即可。远程部署时，需要将本机回调端口 25827 转发到运行 Harness 的机器的同一回环端口。回调服务只监听回环地址，校验 OAuth state，且有有效期和单次消费限制。不要把回调端口公开到互联网。

## 使用

手机图标 → MCP 服务中，各平台“设置”和“模型”抽屉在自己的卡片下方展开。读取型号不会自动勾选或更改默认值。勾选保存后，图片工坊、镜头工坊和 Agent 共用实际启用目录。

可灵动作控制支持一张主体图片，加动作视频或已有动作 ID 二选一；方向和时长限制按当前声明校验。高级参考可读取账号主体库、选择图片/视频主体，并以 `<<<主体ID>>>` 在提示词中引用。提交前重新核对主体归属、实际类型、素材数量和声音组合。已有动作的来源时长仍由服务商校验。

WorkRally 智能编辑把源视频单独绑定到原生 `source_video`，其余素材放入 `reference_assets`。源视频宽、高和时长由本地探测获得，发送时转换为毫秒；生成时长跟随源视频。多段视频同时选择时，明确指定编辑源。当前型号声明支持时，可启用字幕抹除。原生 `VideoEdit` 是另一个协议，不会伪装成 SmartEdit；目录未开放的能力不会自行创建。上游不提供显示名时，界面明确标识，并保留准确型号 ID。

本地素材上限为图片 20MB、视频 300MB、音频 50MB，各服务商或型号可更严格。WorkRally 参考上传当前上限为 50MB。付费任务仍需要宿主授权和界面确认；无法确认提交结果时保留原任务 ID，不自动再次生成。

Agent 通过工坊工具或生成工具传入相同参数：可灵使用 `extra.elements`、`extra.motionId`、`extra.motionDirection`；WorkRally 智能编辑使用 `extra.sourceVideoId` 和可选的 `extra.enable_erase_subtitles`，源视频也必须包含在本次 `reference_ids` 中。模型列表提供模式与参数声明，不接受用额外字段更换账号、接口或服务商。

## 画布生成与重新生成

生成分辨率与画布展示尺寸分开处理：在提示词下方的模型参数中选择当前型号支持的档位（如 1K、2K、4K），界面使用服务商提供的名称，提交保留对应原始参数值。生成出的原文件保留分辨率，在画布上按本次冻结的框选区域宽高显示。没有声明的分辨率选项不会自行补造。

新任务提交时，框选区域显示半透明占位和蓝色像素海豚；首个可用结果落盘后自动加入原位置，其余候选仍可手动加入。旧历史批次不会自动补放。点击生成图片或失败占位，在右上角使用“重新生成”：新任务复用原批次的模型、有效参数、已冻结的参考像素和落点，不读取后来修改过的表单。生成记录页面保持原有重新生成入口。

重复点击不会重复提交；未知结果任务须先核查，不能直接重生成。账号/接口或 API 凭据在重生成入口已变化、旧记录缺少可核对的绑定、原冻结素材缺失时会停止并提示。绑定检查发生在重生成入口，队列后续沿用宿主既有凭据解析方式。自动放置期间有新编辑会保留草稿并提示解决冲突；不会静默覆盖。每次重生成仍是一条新的付费任务，遵守宿主原有授权。

## 验证

```sh
DSH_REQUIRE_NODE_PTC_TESTS=1 npm run test:media
npm run verify
# 浏览器布局回归需要安装测试浏览器
npm exec playwright install chromium
npm run test:media-layout
```

测试使用合成账号、模拟工具和隔离素材，不提交真实付费生成。授权测试在隔离目录中使用临时回调端口，不占用用户的授权端口。通过模拟表示调用和交互契约通过，不等于真实服务的画质、计费或所有下游限制均已验证。
