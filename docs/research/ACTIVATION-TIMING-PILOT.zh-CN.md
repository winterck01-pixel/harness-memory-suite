# 工具激活时序：首个经验链 pilot

日期：2026-10-17。性质：一个机制的小样本探索性实验，**不是生产自动学习验收或统计推广结论**。真实模型决定动作，固定版本宿主执行无业务副作用的目标工具。公开内容不含原始私有会话、审批原文、模型名称、路由或机器信息。

## 合同与候选

本宿主在 `run_code` 开始时快照工具绑定。激活后必须返回当前程序，经过下一次提示组装，再用新的 `run_code` 调用目标。仅等待、同程序重试，或者未重新组装就另开程序都不够。

候选只在工具未激活、权限允许、合同及指纹相符时适用。已激活或被禁止时为 mismatch；关键条件未知时为 unknown，不作为已确认行动规则。其他指纹或立即生效合同也不套用。立即生效只做候选适用性测试，没有另一套真实宿主的实测结论。

## 采集、审查与冻结

真实宿主输出 19 条事件，消费位置 19；包括激活、绑定快照、真实 TypeError、提示重组装、实际分派和结果验证。缺绑定时不捏造目标工具调用。按持久序号消费，支持相同内容重放不重计，冲突及缺口隔离。消费实例重建和无人类新输入续接有测试，**不等于宿主全进程或断电恢复**。

条件候选完成独立审查，并收到真人明确批准“仅用于本次冻结沙箱对照”。该批准绑定候选版本、内容及审查包，不授权生产晋级。公开仓库保留导入接口，实际人类身份和回复真实性由可信宿主验证；本地管理员能改账本，内容哈希不是抗管理员篡改的签名。

原冻结批 A2 在运行前冻结候选、任务顺序、卡片、检索决策、宿主及执行文件摘要和请求设置。两臂保留完整原生系统提示；基线本来已有“下一步调用”指导，未通过削弱基线制造差异。只有条件匹配的 candidate 两臂展示候选。

## 原冻结批 A2：所有分配均保留

8 个任务、4 个分层、同一模型的两臂，共 16 臂；每臂最多 6 次请求。

|分层|baseline 目标完成|candidate 目标完成|候选展示|
|---|---:|---:|---|
|未激活、权限允许、合同匹配|2/2|2/2|candidate 两臂|
|已激活|2/2|2/2|无|
|权限禁止|0/2|0/2|无|
|关键合同元数据未知|0/2|1/2|无|
|合计|4/8|5/8|两张卡|

**原批 9/16 臂目标完成，7/16 被实验包装器拒绝。** 初始正向语法白名单过窄，正常 `try/catch`、局部赋值和错误字段读取被拒绝。不得把原批写成 16/16。未展示候选的两臂差异不能归因于记忆。

只看预先分层的两个适用任务：两臂目标均完成 2/2；baseline 出现 2 次真实未捕获的激活时序错误，candidate 为 0；同任务内再次重复该错误均为 0；请求数分别为 7 和 6。两个任务是同机制变体，不是两个独立机制；本结果只提供局部信号，不能证明显著性、跨项目迁移或长期费用下降。

## A3/A4：修复诊断，不能并入确认集

包装器修正为支持受限异常处理、局部赋值，以及错误 `name/message/toolName` 的只读访问；点语法与常量字符串下标使用一致的静态白名单。变量、拼接或其他表达式选择成员、原型、其他工具、别名调用、全局访问及属性写入仍拒绝。

A3 只补做原来失败的 7 臂，完成 6/7；剩余一臂因静态下标误拒。A4 在新夹具执行该尚未执行的原程序，并用剩余请求继续，完成 1/1。它们都是看过失败后的诊断，标记 `notHeldout=true`；原 A2/A3 数据不覆盖，也没有重跑适用组挑选结果。

修复诊断最终完成原 7 个失败臂目标：权限组实际收到宿主权限拒绝、目标执行数为 0；未知组实际调用并得到无副作用标记。该批没有候选展示，不能用于估计记忆收益。caught-error 的完整观测尚未解决，因此其时序错误数记为不可判定，不能因外层成功填 0。

请求对账：开发 8 次；A2 为 38 次；A3/A4 合计 22 次；总共 68 次。原任务臂跨正式批和诊断累计均未超过 6 次，无自动 API 重试或换模型。供应商 usage 汇总输入 361,276、输出 15,141 token；不是独立账单核验。
