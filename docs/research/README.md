# 研究、算法与实验说明

本项目研究如何把真实任务中的错误、修复与经检查的成功方法转化为后续可复用经验。首次探索允许走弯路；目标是避免重复已证伪的做法，并在条件相符时复用成功方法，同时保持任务质量和当前授权。

本系统通过外部记忆、检索和程序资产改变上下文，不更新底层模型权重。研究方案、实验验证、影子接入和正式行动注入是不同状态。

## 阅读顺序

1. [完整架构、算法与数学设计](EXPERIENCE-LEARNING-DESIGN.zh-CN.md)：事件证据、条件候选、经验与技能分层、八项基线遗漏的对应机制、迁移和回滚。
2. [文献来源与借鉴边界](REFERENCES.zh-CN.md)：22 项原始来源、证据类型、实际借鉴与不能推导的结论。
3. [工具激活时序 pilot](ACTIVATION-TIMING-PILOT.zh-CN.md)：原冻结批的失败、补充诊断和局限全部分开。
4. [全新任务冻结确认](ACTIVATION-TIMING-CONFIRMATION.zh-CN.md)：12 个分配、36 次请求，包含捕获错误不可完整观测的限制。
5. [实现与部署状态](STATUS.zh-CN.md)：区分当前源码、隔离验收及历史运行记录。
6. [成功方法安装与使用](../SUCCESSFUL-EXPERIENCES.zh-CN.md)与[主动复用缺口](EXPERIENCE-REUSE-GAPS.zh-CN.md)：已实现的条件历史通道，以及暂缓继续试验的检索和衔接问题。

## 实现边界

|能力|状态|
|---|---|
|原生执行事件、可信定时来源、单写者幂等账本、来源/内容/审核指纹|已实现；持久化来源需满足官方只读观察契约|
|条件三值判断、审核与冻结守卫、来源撤回、沙箱检索|隔离切片已实现；真人回执必须由可信调用方认证|
|原生任务流程影子采集与自动生成待审候选|已接通；待审失败候选不直接进入正常提示|
|冻结单候选对照|首个小样本 pilot 完成；有包装器失败，不能写为全通过|
|自动配对评测与工具激活沙箱|已实现来源、预算、曝光和结果账本；激活域只限沙箱，不自动晋升|
|日常恢复与固定机制受限提示|显式启用；固定本地契约验证，不等于任意工具操作经验自动认证|
|有来源和条件的成功方法|已实现保存、检索、采用与后续结果核对；不是独立质量或因果收益证明|
|模糊任务的主动经验复用|仍有检索与工具交互缺口；后续改进暂缓，未声称已经解决|
|一般机制自动提炼、预算覆盖优化、Beta/分层模型、价值复盘|总体方案，尚未据此证明效果|
|旧统计候选晋级与正式技能自动注册|不因采集或实验通过自动开启；本次同步不解除旧冻结，旧冻结也不代表其它独立历史通道关闭|

实验入口见[可复用切片](../../experiments/activation-timing/README.zh-CN.md)。原始运行日志、人类审批原文、模型路由和机器信息不公开；因此公开材料支持检查方法和复现实验，不允许读者声称已经独立复核私有运行原文。
