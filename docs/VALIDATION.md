# 验证范围

`npm run verify` 执行隐私模式、JavaScript 语法和各模块的已包含测试。文件客户端测试会重新构建产物。`npm run prepare:host` 是测试依赖准备，不会自动接入生产宿主。

上下文策略使用公开包导入和纯合成目录。真实 ToolRuntime、SystemPrompt、native/PTC bindings 与 guards 参与执行；叶子操作和 workingDirectory service 为明确的合成 fixture。测试要求未激活能力被拒绝、显式激活后可执行、关闭记忆与禁止工具不能被越过、下一轮和持久事件恢复保持边界。没有静默退回旧版自动路由或 full 激活契约。

第三方转换工具缺失时，一些知识格式测试可能按明确条件跳过；运行结果必须分别报告通过、失败及跳过，不能把依赖缺失解释为功能验收。知识库网络与 provider 测试使用模拟响应，不提交付费请求。

阅读器客户端及字体/解码器保留随包发行文件与上游许可证，源码集不声称能够从不存在的原始 UI 源重新构建这些上游产物。可选模块和真实宿主浏览器行为仍需要部署者单独验收。

测试全部通过仍不能证明：开放域语义检索无噪声、长期任务收益、所有宿主版本可用、任意 provider 可用，或自动采纳已获准。候选推广需要按候选身份绑定、预先冻结并配对的独立任务结果。
