# 执行经验候选

这条独立链路把可信执行事件转成有来源、适用条件和缺失证据说明的待审候选。失败正文、参数、提示词和推理正文不保存到候选账本；原生会话是证据正文来源。它不改模型权重，也不把失败直接写成长期记忆。

## 数据流与来源

1. 监听当前活跃会话的原生事件，独立于普通捕获的真人输入门控，不改变 `postTurn`、`taskEnd` 或专用新闻事实写入的原义。
2. 定时来源同时匹配宿主 session 对象、项目 scope、原生事件、官方单任务/批次消息格式，以及 `schedule.catalog()`、`schedule.history()` 中的消息 ID、交付时间和原提示回执。仅声称 `source.kind=schedule` 不够；批次必须完整匹配。
3. 保存事件引用、哈希、工具调用关联和明确结果等级，消费有动作及结果的完整轮次。工具失败、后来同工具成功、独立验证分开记录；最终完成不证明修复有因果效果。
4. `mnemo_experience` 提供当前项目的 `status/list/inspect/review`。查看和审查前重核来源；review 经宿主真人问答绑定当前 packet，批准范围仅限冻结沙箱评估资格。

适用条件包括项目、宿主合同、来源类型、任务身份及原提示版本哈希、涉及工具；未知权限和环境明确标为 unknown。候选保持 `needs-review`、`productionEligible:false`、`frozenOnly:true`、`instruction:null`。真人回执单独记录，不调用 `acceptProposal`，不进入普通 recall、注册技能或解除冻结。

## 恢复与失效

- 事件投影、连续游标和候选原子提交；重复事件、重复回执通知和重启不重复生成候选。
- 来源登记从当前活跃轮次建立，不扫描历史会话目录。已登记来源冷却后，通过官方 `sessionQuery` 的只读观察租约与 `sessionPersistence.stat` 复核，按预算补读未消费轮次；不恢复旧 Agent、不打开新写者，也不把旧 trial 原文自动升级为经验。无持久化读取契约时只支持准确的活跃来源。
- 回执可能晚于任务结束落库。`schedule/changed` 重试已知待采来源后再核验候选，不创建新任务或调用模型。
- 服务暂不可用时保留候选待重核，并撤掉可用批准；服务恢复后旧批准不会自动恢复。
- 来源撤回、原生事件变化、同轮追加证据、scope 或合同变化使旧审查失效，保留无正文的审查哈希。后来修改的任务提示不替换旧交付回执。
- 真人禁记延续到无人续轮；定时消息不能重置禁记，任务原提示的禁记也生效。只读实例和失去写锁的提交拒写。
- 源、事件、候选和文件大小分别受预算限制。容量不足明确暂停，不静默挤掉未消费来源或跳过缺号游标。

## 配置与使用

在已有 MNEMO 插件条目的 config 中配置，不要安装第二个记忆写者：

```yaml
executionExperience:
  enabled: true
  contractFingerprint: "<部署者核对的64位小写SHA256>"
  maxEvents: 10000
  maxSources: 64
  maxTotalEvents: 10000
  maxCandidates: 1000
  maxBytes: 8388608
```

默认关闭。合同指纹应绑定实际宿主、会话/定时服务、采集实现和执行政策；升级后重新核对。可选 `allowedTaskIds` 限制为部署者指定任务集合。运行数据在配置数据目录的 `execution-experience/` 下，必须保持私有，不提交 Git。若只需要采集和人工审查，另显式配置 `autoLearning.enabled: false`；否则执行采集启用后会尝试构造自动评测器，可信策略匹配时可能调用模型。

`/mnemo status` 的 `adapter.executionExperience` 提供聚合状态与预算。本仓库 `context-policy` 已将 `mnemo_experience` 纳入基础可见集，仍须满足宿主注册、权限与禁记约束；其他组合按实际宿主工作流激活。先 inspect 取得 `reviewPacketHash`，再用相同 ID 与 packetHash 请求 review。模型自述同意、自由文本、旧指纹、来源变化或中途取消都不能产生有效批准；批准不等于评估通过。

## 模拟验收与边界

MNEMO 正式回归套件已移除，当前不再提供 `npm test --workspace=dsh-mnemo` 入口，根目录 `verify` 也不再执行该套件。清理前的隔离模拟覆盖真实插件接线、官方回执格式、回执延迟、来源伪造、禁记、重启去重、配额、只读与写锁撤销、源变化、审查期间撤回/取消，以及长期记忆与冻结状态不变；没有付费请求。

这些检查证明证据到待审候选链路，不证明候选已改善后续任务。没有可信来源的无人续轮仍拒绝；自然语言修复规则、因果验证和生产收益需单独验收。另行显式启用的[成功方法](SUCCESSFUL-EXPERIENCES.zh-CN.md)可以按条件检索历史卡片，但不会把本页未经审查的失败候选直接送入普通记忆检索。
