# Harness Memory Suite

面向兼容 Harness 宿主的记忆、知识、技能与按需能力编排源码集。当前为受控初版：具备版本、来源、作用域、使用声明、候选评估和安全边界；自动采纳是否开放必须由独立任务结果决定，测试数量或召回次数本身不是晋级依据。

## 模块

|目录|职责|
|---|---|
|packages/mnemo|工作记忆、暂存捕获、版本与来源、显式使用收据、检索、候选评估|
|packages/knowledge-vault|持久知识、分片与检索、来源授权、OCR/向量接口|
|packages/reader|文档读取与格式处理，接入知识库的执行上下文与结果校验|
|packages/file-manager|文件交互及知识入口，含可构建客户端源码|
|packages/dsh-skill-lifecycle|技能验证、修订核对、显式加载与能力元数据检索|
|packages/dsh-skill-manager|技能浏览、编辑与来源冲突管理界面|
|packages/context-policy|显式发现/激活工具，按会话约束投影上下文；不接受 full 绕过|
|packages/session-router|可选的跨会话创建、转交及会话模型选择；版本漂移时关闭相关桥接|

`patches/dsh-tools-compat.patch` 为固定宿主版本补充结果重新校验与能力可用性过滤。它是本套件部分模块的必要宿主契约，不能省略后仍宣称行为等价。补丁附原始及目标文件校验和，不包含完整宿主发行版。

## 本地检查

需要 Node.js 22.19 或更新的受支持版本、npm、Git 和 `patch` 工具。

```sh
npm ci --ignore-scripts
npm run prepare:host
npm run verify
```

准备脚本默认只修改本仓库的开发依赖副本，版本/校验和不匹配会拒绝。原文件保存在被忽略的 `.cache` 中。发布前应另用密钥扫描工具检查暂存文件和 Git 历史；`check:privacy` 是保守模式检查，不保证能识别未知敏感信息。

验证包含记忆、知识库、文件客户端与上下文策略的测试。上下文策略测试包含真实 SDK 的 native/PTC 调用，叶子操作、工作目录和目录索引均为合成 fixture；不执行真实业务操作或模型请求。阅读器、技能管理和可选路由目前不单独声称完整浏览器交互验收。

## 接入宿主

参见 [接入说明](docs/INTEGRATION.md)。先在隔离宿主检查；选择数据目录、来源根和 provider 凭据属于操作者的本地配置，不随源码分发。文本 provider 预设默认禁用，模型字段仅为 `configure-…-text-model` 占位符，启用前必须替换为操作者选择的实际模型。

此仓库只包含发布源码、合成测试、通用说明与可移植兼容补丁；不包含真实记忆、会话、模型协作过程、实验回答、运行凭据、部署回执或机器配置。测试中的项目名、路径与标识符均为通用合成样例。公开 SDK/API 标识和第三方许可证按兼容与署名要求保留。

## 边界与授权

曝光不等于使用；声明使用不等于已验证的效果；历史授权不等于当前授权。作用域与整轮关闭记忆约束应贯穿捕获、检索、注入及使用报告。升级与补丁应用都需要核对宿主契约，不能覆盖未知版本或既有数据。

本仓库的测试通过不证明开放域检索、长期任务收益、宿主现场状态或自动采纳已经达标。详见 [验证范围](docs/VALIDATION.md)。
